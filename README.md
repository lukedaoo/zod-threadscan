# zod-threadscan
zod-threadscan is a tiny experimental tool for exploring multithreading in C++.
It scans all files in a directory and searches for a given text using multiple threads.
# Purpose
- Learn how to create and manage multiple threads in C++
- Practice synchronization, work distribution, and file scanning
# Requirements
- C++17 compatible compiler
- GCC recommended
